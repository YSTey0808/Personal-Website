Binance Agentic AI Challenge · 2026 +1.2%14-day live run

Quantelligence: Multi-Agent LLM Trading System

LLM agents that traded bStocks autonomously over a 14-day unattended live run, returning +1.2% in a falling market. An event-driven trigger gate (deterministic rules + LLM news classification) decides when the agents run; technical, news and fundamentals analyst agents, tuned via an LLM judge, pass their findings to a quant trader, then a risk analyst, then a portfolio manager. A claim-verification layer checks every analyst claim against source data and auto-rejects unsupported ones.

My role: designed the LangGraph agent architecture and owned all DevOps for a 4-person team: deployment across two GCP VMs with a Postgres fallback, plus the reliability plan (recovery watcher, health APIs, standby price feed) for a run that allowed no manual intervention.

  • Finalist (top 25) · 3rd of 25 finalist teams by final total assets
  • +1.2% over a 14-day unattended live run
  • 97% of 1,800+ claims grounded across 134 live reports
  • 92% recall · 3% false triggers on 80 scenarios (50 must-fire, 30 must-stay-quiet) + a simulated trading week
  • 90% fewer noise alerts after retuning

Huawei Tech4City · May – Aug 2026 96.04%accuracy

Real-Time Harm Detection Platform

Flags grooming, scams and cyberbullying in code-mixed Singlish / Manglish chat, where off-the-shelf moderation models fail. Each conversation becomes a graph scored for risk by a GraphSAGE GNN over XLM-RoBERTa embeddings, and an LLM confirms the verdict and explains every flag back in the chat within seconds. Synthetic Singlish / Manglish conversations teach the model local slang that public datasets lack.

My role: co-designed the detector and owned the platform end to end in a 5-person team — React/TS chat app, FastAPI, Supabase data layer and Realtime, GCP hosting — serving the detector in live chat and driving end-to-end pipeline testing.

  • 96.04% accuracy on 227 conversations
  • 100% harmful-actor detection · 1 false flag
  • 20-user pilot

TikTok TechJam · 2026 98.5%Hit@10

Conversational Shopping Search Agent

A multi-turn agent that finds a shopper's target among 50,000 catalog items through a 3-stage pipeline (retrieve, rank, LLM rerank). It turns customer words into catalog facets, fuses BM25, category and vector retrieval with reciprocal rank fusion, reranks against a shopper profile, and uses a decision tree to pick the clarifying question that best splits the remaining candidates.

My role: led integration and orchestration of the pipeline and wired the conversation loop end to end; built the LLM reranker, the clarifying-question decision tree, and the self-evolving context module that distils each conversation into a compact shopper profile and adapts the questioning strategy at runtime.

  • 98.5% Hit Rate@10
  • 2.6 turns on average
  • MRR 0.44 → 0.64
  • 8× the BM25 baseline score

Open source · 2026 Fail-safeby design

Code Intent Analyser — LLM PR Security Gate

A GitHub Action that reads every pull-request diff for deliberate harm — exfiltration, backdoors, logic bombs, CI/CD tampering — using a local Ollama model, so no code leaves your infrastructure. It scores risk 0–100 and posts a sticky PR comment explaining the change.

Design rule: a failure or manipulation must never open the gate. Every error path escalates to review or block, never to pass.

  • Schema-constrained JSON verdicts
  • Prompt-injection tripwire
  • Standard-library Python only (no pip dependencies)
