How I work

Three habits I bring to every project

01

Understand the problem properly

Off-the-shelf moderation fails on Singlish, and shoppers don't use catalog words. Finding the real constraint first decides which design will actually work.

02

Build the smallest thing that solves it

Python standard library only, if that's enough. A thin API over a well-separated model. Less surface area means fewer ways to fail.

03

Measure whether it worked

Recall and false-positive rate, Hit@10 and MRR, pilot results with real users. Where safety matters, I fail closed and tune toward coverage.
