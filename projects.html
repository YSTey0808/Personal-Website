Open source · 2026 Fail-safeby design

Code Intent Analyser — LLM PR Security Gate

A GitHub Action that reads every pull-request diff for deliberate harm — exfiltration, backdoors, logic bombs, CI/CD tampering — using a local Ollama model, so no code leaves your infrastructure. It scores risk 0–100 and posts a sticky PR comment explaining the change.

Design rule: a failure or manipulation must never open the gate. Every error path escalates to review or block, never to pass.

  • Schema-constrained JSON verdicts
  • Prompt-injection tripwire
  • 0 third-party deps
